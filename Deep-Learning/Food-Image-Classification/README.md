# Food Image Classification

## Problem statement

Clicks, a stock-photography company, receives too many food images for manual labeling. The project builds an image classifier for three categories: Bread, Soup, and Vegetables-Fruits.

## Analytical objectives

- Load and inspect image data organized by class.
- Resize, normalize, and transform images into model-ready arrays.
- Build and evaluate convolutional neural networks.
- Compare model behavior and identify practical improvements.

## Techniques

Computer vision, image preprocessing, convolutional neural networks, TensorFlow/Keras, dropout, model evaluation, and confusion analysis.
