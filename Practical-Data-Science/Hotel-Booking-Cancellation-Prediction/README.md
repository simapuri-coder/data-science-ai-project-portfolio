# Hotel Booking Cancellation Prediction

## Problem statement

INN Hotels needs to predict bookings that are likely to be canceled so it can reduce lost revenue, improve room allocation, and design more effective cancellation and refund policies.

## Analytical objectives

- Analyze booking behavior and cancellation drivers.
- Build classification models for canceled versus retained bookings.
- Balance precision and recall using F1 score.
- Translate feature importance into operating recommendations.

## Techniques

EDA, classification, decision trees, random forests, hyperparameter tuning, confusion matrices, F1 score, and feature importance.

## Key result

The analysis identifies lead time, special requests, online market segment, and average room price as important cancellation drivers. The strongest random-forest configuration reaches an F1 score of approximately 0.85 on test data.
