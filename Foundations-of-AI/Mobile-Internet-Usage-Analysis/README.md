# Mobile Internet Usage Analysis

## Problem statement

A service provider reports that Americans spend an average of 144 minutes per day accessing the internet on a mobile device. A sample of 30 users is analyzed to test whether the true population mean differs from that claim.

## Analytical objectives

- Formulate null and alternative hypotheses.
- Apply a two-sided z-test at a 5% significance level.
- Calculate the test statistic and p-value.
- Translate the statistical decision into a clear business conclusion.

## Techniques

Python, pandas, SciPy, hypothesis testing, z-tests, p-values, and statistical inference.
