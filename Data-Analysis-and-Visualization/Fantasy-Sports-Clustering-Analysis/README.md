# Fantasy Sports Clustering Analysis

## Problem statement

OnSports needs a data-driven way to price English Premier League players for a new fantasy season. Historical performance data is segmented to identify groups of players with different fantasy potential and expected value.

## Analytical objectives

- Explore player performance, playing time, influence, and fantasy returns.
- Prepare and scale numeric features for unsupervised learning.
- Compare clustering approaches and select an appropriate number of clusters.
- Profile the clusters and convert them into pricing recommendations.

## Techniques

EDA, feature scaling, PCA, K-Means, hierarchical clustering, K-Medoids, Gaussian mixtures, DBSCAN, silhouette score, and business visualization.

## Key result

The final K-Means solution uses four player segments. The notebook identifies a high-value cluster for premium pricing, two lower-engagement groups for value or backup pricing, and a middle segment of influential players.
