# Book Recommendation System

## Problem statement

An online bookseller needs relevant recommendations that reduce discovery time and increase customer engagement. The project compares popularity-based and personalized recommendation strategies using book-rating interactions.

## Analytical objectives

- Build a rank-based recommender for cold-start scenarios.
- Develop user-user and item-item collaborative-filtering models.
- Build a matrix-factorization model with SVD.
- Evaluate recommendations with RMSE, precision@k, recall@k, and F1@k.

## Techniques

Data preparation, popularity ranking, collaborative filtering, KNN, matrix factorization, SVD, grid-search tuning, and top-N recommendation functions.

## Key result

The optimized user-user collaborative-filtering model produces the strongest F1 score in the notebook (about 0.86), while matrix factorization provides competitive predictive accuracy with RMSE near 1.50.
